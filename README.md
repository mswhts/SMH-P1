harvest simulator;
its a web based weather lab sorta game.
its a digital farm with crops that are affected by all factors, such as weather, time, soil, etc. 
its in a very early stage, what it contains at this stage:
10x10 grid of crops,
basic layout,
advance time by 1 hour button which affects soil, weather, wind change.
its not much at the moment, all it does it show how time affects factors at this point.
