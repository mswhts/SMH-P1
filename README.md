This project is on a game-like farming simulator exploring crop growth under various environmental conditions.
description:
Simulation of interactive farming in which one will be able to explore the effects of the climate and the environment on crops. 
The player will run there virtual farm by selecting crops, growing them, watching the soil environment, 
reacting to changes in the weather and harvesting them.

techstack used:
 HTML5, CSS3,JS GitHub,  Pages

how to use:
1. Open the demo link -> https://mswhts.github.io/SMH-P1/
2. move sliders, select a crop then click a plot to plant (the numbers on the plot repersents the soil).
3. Click the empty farm field to plant a crop.
4. Observe weather, soil moisture and crop state.
5. Water crops, if needed.
6. Advance time manually or starts automatic simulation.
7. Harvest crops when they are fully grown.
8. Use harvest yield to earn money and buy new seeds.
